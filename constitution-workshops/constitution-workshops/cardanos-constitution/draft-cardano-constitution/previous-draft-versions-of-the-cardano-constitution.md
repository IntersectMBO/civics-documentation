# Previous draft versions of the Cardano Constitution

### Versioning of the draft constitution

The first version of the draft constitution (not to be confused with the [interim](https://docs.intersectmbo.org/cardano/cardano-governance/cardano-constitution/interim-cardano-constitution) currently live on mainnet) was made available at the end of July 2024 and before the start of the workshop series. Following the conclusion of the series and 63 workshops, the Civics Committee began collating and adjusting the July version, resulting in seven additional delegate workshops to synthesise the collective feedback. You can now review all the raw inputs from the global workshop series [here](constitutional-workshop-outcome-material.md).

The three versions below account for the revisions provided during the delegate synthesis workshops, and are dated between October 30th and November 15th. \
\
Following the final synthesis workshop on November 16, the latest version of the draft Constitution is now available and can be found [here](./).&#x20;

### Explainer

**Clean version** have all changes included to that date, but does not show what has been changed. \
\
**Markup version** shows all the changes that were made from the previous version. \
For the most recent version of the draft constitution, please see [here](./).
