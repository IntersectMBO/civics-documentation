# How to participate

You can participate using the Web Application found here - [https://1694ballot.cardano.org](https://1694ballot.cardano.org/)\
\
Since Cardano Ballot is a stake-based voting application, submitting a vote using Cardano Ballot requires

(1) a browser extension wallet (software wallet) supporting CIP-30 - [List of supported wallets](list-of-supported-wallets.md), and (2) a minimum of one Lovelace staked before Nov 21st.\
