# Learning Outcomes and Expectations

Participants who take this program will be able to:

1. Understand the fundamentals of Cardano’s on-chain governance design
2. Understand the role and expectations of a DRep
3. Gain the skills to effectively became a Drep - both the practical and the ‘softer’ skills (e.g. marketing, building relationships)
4. Be able to engage with the community with available tools
