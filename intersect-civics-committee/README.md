# Cardano Civics Committee (Civics)

## What is the Civics Committee?

The Cardano Civics Committee exists to make sure Cardano's governance is accessible, fair, and transparent.

We facilitate and oversee. Cardano's governance depends on work that nobody is obliged to do: the Constitution had to be consulted on, Constitutional Committee seats have to be refilled when they expire, tooling has to be maintained and paid for. We make sure that work has a mandate, a process, the people to do it, and someone seeing it through to the end.
